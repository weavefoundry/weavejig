# Contributing

- **Commits:** one-line [Conventional Commits](https://www.conventionalcommits.org/), with no scope and under 60 characters (e.g. `feat: add one-statement-per-line rule`).
- **Branches:** the same format, with `/` after the type (e.g. `feat/add-one-statement-per-line-rule`).
- **PR titles:** the same format as commits, since PRs are typically squash merged using the title as the commit message.
